# Дизайн-система Ender Trails — пиксельный «майнкрафт»-стайл

Единственный источник правды по внешнему виду. Код — `lib/shared/design_system/`.

---

## 0. Главное правило

**Стилизация, не копирование.** Никаких ассетов Mojang: ни шрифта Minecraft,
ни текстур блоков, ни звуков, ни логотипа. Это чужая интеллектуальная собственность,
за неё банят в сторе. Мы делаем **свой** пиксель-арт в похожей стилистике.

Что можно и нужно брать: саму идею — блоки, фаски, редстоун, опыт, печь, рычаг,
эндер-тему (название `Ender Trails` про Энд, это наша тема, а не ихняя).

## 1. Шрифт

**`PixCyrillic`** (форк Pixellari) — SIL OFL 1.1, полная кириллица (рус/укр/бел).
- Файл: `design/fonts/PixCyrillic.ttf` → в приложении `assets/fonts/PixCyrillic.ttf`
- Лицензии `PixCyrillic-LICENSE.txt` и `Pixellari-LICENSE.txt` **обязательно** едут
  в бандл и в экран «О приложении» (требование OFL).
- OFL не требует открывать исходники приложения. Резервированные имена
  («Pixellari», «Pix Cyrillic») — не переименовываем шрифт, и всё.

Разделение по назначению:

| Где | Шрифт | Почему |
|---|---|---|
| Заголовки, кнопки, цифры, лейблы, статусы | `PixCyrillic` | атмосфера |
| Длинный текст: политика, FAQ, описание тарифа, ошибки на 2+ строки | системный sans (Roboto) | пиксельный шрифт на «простыне» нечитаем |

Размеры пиксельного шрифта — только кратные сетке, чтобы не мылить:
`12 / 16 / 20 / 24 / 32`. `height: 1.0`, `letterSpacing: 1.0`.

```dart
// Один TextStyle на всё приложение, дальше только copyWith
static const pixel = TextStyle(
  fontFamily: 'PixCyrillic',
  height: 1.0,
  letterSpacing: 1.0,
);
```

### Семантика статуса

| Статус | Цвет лампы | Текст (RU) | Текст (EN) |
|---|---|---|---|
| `disconnected` | `#7A7A85` (камень) | Отключено | Disconnected |
| `connecting` | `mcGold` (мигает) | Подключаемся… | Connecting… |
| `connected` | `mcGrass` (+свечение) | Подключено | Connected |
| `reconnecting` | `mcGold` | Переподключение | Reconnecting |
| `error` | `mcRedstone` | Ошибка | Error |

**Никогда не передаём статус одним цветом** — всегда лампа + текст.

## 3. Геометрия

- `BorderRadius` = **0** везде. Круглых кнопок не существует.
- Вместо теней — **блочная фаска**: 3px светлая полоса сверху и слева,
  3px тёмная снизу и справа, поверх — 2–3px чёрный контур.
- Отступы кратны 4: `4 / 8 / 12 / 16 / 24 / 32 / 48`.
- Толщины линий: контур 2px (мелкие элементы) и 3px (карточки, кнопки).
- Внешняя жёсткая тень (без размытия): `Offset(4, 4)`, цвет `mcInk` с alpha 0.6.

```
┌──────────────────────────┐  ← контур 3px чёрный
│▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓│  ← светлая грань (3px)
│▓                        │
│▓      СОДЕРЖИМОЕ        │
│                       ░░│  ← тёмная грань (3px)
└──────────────────────────┘
```

## 4. Компоненты

### `BlockButton`
Базовая кнопка. Состояния: `enabled / pressed / disabled`.
- `pressed`: фаска инвертируется, содержимое смещается на `(2, 2)`.
- Варианты: `stone` (обычная), `ender` (акцент), `grass` (подтверждение), `redstone` (опасная).
- Высота 48, паддинг по горизонтали 16, текст 16px пиксельным.

### `LeverButton` — главная кнопка подключения
Квадратный блок **192×192** по центру главного экрана.
- Отключено: серый камень, рычаг вниз.
- Нажатие: рычаг «щёлкает» вверх — анимация из 4 дискретных кадров, без интерполяции.
- Подключено: блок светится изумрудным, рычаг вверх.
- Подключение: золотой, рычаг дрожит (2 кадра).
- Ошибка: красный, рычаг вниз + иконка.
- Под блоком — статус лампой + текстом.

### `StonePanel`
Карточка: фон `mcStone`, контур 3px `mcInk`, фаска, паддинг 12/16.

### `XpBar` — шкала трафика
Как шкала опыта: сегменты по 12px с зазором 2px, высота 12.
- Заливка `mcGrass`, фон `#1F1F26`, контур 2px `mcInk`.
- Если трафика > 80% — заливка `mcGold`, > 95% — `mcRedstone`.
- Безлимит: показываем использованный объём без шкалы, подписью «Безлимит».

### `SignalBars` — пинг сервера
5 столбиков («уровень сигнала»), как в списке серверов:
```
< 100 мс  ▁▃▅▇█  зелёный
< 200 мс  ▁▃▅▇    салатовый
< 350 мс  ▁▃▅     золотой
> 350 мс  ▁▃      красный
нет ответа ▁       серый, «нет ответа»
```

### `RedstoneLamp`
Квадрат 16×16 с внутренним квадром 8×8. Включена — цвет статуса + мягкое свечение
(`BoxShadow`, только для неё можно blur, это свет лампы).

### `ServerRow`
Строка списка серверов (высота 64):
`[код страны в «табличке»] [Название · протокол] [SignalBars + ms]`
- Флаги **не рисуем** — вместо флага двухбуквенный код страны (`NL`, `DE`, `KZ`)
  в блоке-«табличке». Дешёво, читаемо, не надо рисовать 200 спрайтов флагов.
- Выбранная строка — обводка `mcLapis`, фон чуть светлее.

### `FurnaceLoader`
Индикатор загрузки — «печь» с двумя кадрами пламени (0.4 с на кадр).
Используется там, где ждём дольше 1 секунды.

### Прочее
- `PixelSwitch` — прямоугольный тумблер, бегунок — блок (не круг).
- `PixelAppBar` — `mcDeepslate`, контур 3px только снизу, заголовок 20px пиксельным.
- `PixelDivider` — пунктир 2px через 4px, цвет `mcStoneLight`.
- `PixelToast` — блок, выезжающий снизу ступенчато (3 кадра), живёт 2.5 с.
- `PixelIcon` — 24×24, сетка 16×16, штрих 2px, без сглаживания. Свой спрайт-лист.

## 5. Движение

- Кривые — **ступенчатые**: `StepsCurve(steps: 4)` или явная покадровая анимация.
- Длительности: `80 мс` (клик), `160 мс` (переход экрана), `320 мс` (рычаг), `400 мс` (плавление печи).
- **Material Splash отключён** (`NoSplash.splashFactory`) — вместо него «вспышка блока»:
  фон на 80 мс становится на тон светлее.
- Ripple, Hero-переходы, `FadeTransition` — не используем. Экраны меняются
  «слайдом по сетке» (смещение на 8px за кадр).

## 7. Доступность (не жертвуем стилем, но и не калечим)

- Пиксельный шрифт — минимум 12px, только для коротких строк.
- Длинные тексты — системным sans, 14–16px, `height: 1.5`.
- Статус = цвет + текст + форма лампы (не только цвет).
- Контраст текста на камне: `#E6E6E6` на `#1B1B22` ≈ 14:1 — запас большой.
- Touch target — минимум 48×48, даже если визуально блок меньше.
- Проверять масштаб шрифта системы до 1.5× — главный экран не должен ломаться.

## 8. Техническая заметка по Flutter

- Pixel-perfect: сборка на密度 2.0/3.0 не мылит шрифт, если размеры кратны сетке.
- Отключаем `Material` там, где он мешает: `ThemeData(splashFactory: NoSplash.splashFactory,
  useMaterial3: true)`, кастомные `ButtonTheme`.
- Иконки — **не** `Icon(Icons.*)`:Material Icons ломают стиль. Свой `PixelIcon` из спрайта.
- Шрифт подключаем через `pubspec.yaml` → `flutter: fonts:`, не через `GoogleFonts` —
  офлайн-работа и гарантированная кириллица.
